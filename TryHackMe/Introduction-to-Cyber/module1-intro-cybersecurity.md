# Module 1 - Introduction To Cyber Security
 **Date completed: May 21, 2026**

## Offensive Security 
- Breaking into systems to find weaknesses
- Example job: Penetration Tester 

## Defensive Security 
- Protecting system from attacks
- Example job: SOC Analyst

## What I learned 
- Hackers are not always bad - ethical hackers help companies 
- A SOC Analyst monitors the system and responds to attacks 
- The goal of cybersecurity = protect data and systems
